Welcome to the **Social Network Visualizer (SocNetV)** manual, your comprehensive guide to exploring, analyzing, and visualizing social networks. 
Whether you're new to network analysis or a seasoned researcher, this manual will walk you through every aspect of SocNetV, from understanding the user interface to leveraging advanced analysis tools.

Dive into detailed sections on:

- [Network Formats](/manual/formats): Learn how to load and manage networks in various supported formats.
- [Generating Networks](/manual/generate): Explore random network models and recreate famous datasets.
- [Network Analysis](/manual/analysis): Discover the powerful metrics and algorithms SocNetV offers for deep network insights.
- [Visualization and Exporting](/manual/visualization): Customize your visualizations and export high-quality outputs for your research or presentations.

Explore the sidebar or the table of contents below to get started. You might also want to check the [Credits](/manual/credits) and [References](/manual/references) sections.

Happy analyzing!

Looking for the source code documentation? The annotated API reference (generated from the C++/Qt source) is available at [/docs/index.html](/docs/index.html). You can also browse or clone the repository on [GitHub](https://github.com/socnetv/app).
:::
