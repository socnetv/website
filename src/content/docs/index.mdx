## Free and Open-Source Tool for Social Network Analysis 🌟 

<Image loading src={myImage} alt="SocNetV v3.5 main window — Zachary's Karate Club network visualized with Kamada-Kawai layout and betweenness centrality node colour coding, with Control Panel and Statistics Panel visible." />

SocNetV is a cross-platform, free and open-source application for social network analysis and visualization. Draw networks with a few clicks, load data from dozens of file formats, run analysis, and produce beautiful reports — all from an intuitive interface that works on Windows, macOS, and Linux.

---

## Main Features 🚀

<CardGrid stagger>

  <Card title="Easy User Interface" icon="open-book">
    <p>Draw <a href="/manual/gui/#creating-and-handling-nodes">nodes</a> and <a href="/manual/gui/#creating-and-editing-edges">edges</a> with a few clicks on a <a href="/manual/gui/#canvas">virtual canvas</a>, or import data from a file in a <a href="/manual/formats">supported format</a>. <a href="/manual/gui/#tooltips-and-context-menus">Right-click any element</a> for context actions. Customise each node's label, size, color, shape, and even use your own image as a node icon.</p>
  </Card>

  <Card title="Network Analysis" icon="seti:graphql">
    <p>
      Compute <a href="/manual/analysis/#cohesion-measures">cohesion metrics</a> (density, diameter, distances, clustering coefficient, reciprocity),
      <a href="/manual/analysis/#centralities-and-prestige"> centrality and prestige indices</a> (betweenness, closeness, eigenvector, PageRank, and more),
      <a href="/manual/analysis/#community-detection"> community detection</a> (triad and clique census), and
      <a href="/manual/analysis/#hierarchical-cluster-analysis-hca"> structural equivalence</a> analysis.
    </p>
  </Card>

  <Card title="Visualization" icon="seti:pipeline">
    <p>
      Apply layouts based on prominence scores (circular, radial, level),
      force-directed models (<a href="/manual/visualization/#kamada-kawai-layout">Kamada-Kawai</a>, <a href="/manual/visualization/#fruchterman-reingold-layout">Fruchterman-Reingold</a>, <a href="/manual/visualization/#spring-embedder-layout">Spring Embedder</a>),
      or the <a href="/manual/visualization/#ego-centered-radial-layout">ego-centered radial layout</a> to explore a node's neighborhood in depth.
    </p>
  </Card>

  <Card title="Graph Exploration" icon="magnifier">
    <p>
      Non-destructive <a href="/manual/gui/#filtering-and-graph-exploration">filters</a> let you isolate any part of the network — ego network, selection, attribute value, centrality score, or edge weight — without losing data.
      A persistent <a href="/manual/gui/#filter-bar">filter bar</a> shows active conditions as chips you can clear one by one or all at once.
    </p>
  </Card>

  <Card title="Data Management" icon="list-format">
    <p>
      Attach <a href="/manual/data/#node-and-edge-custom-attributes">custom attributes</a> to nodes and edges, browse and inline-edit everything in the <a href="/manual/data/#data-table-dock">Data Table dock</a> (<code>Ctrl+T</code>),
      and <a href="/manual/data/#exporting-nodeedge-data-as-csv-or-json">export to CSV or JSON</a> for bulk editing in any spreadsheet tool.
    </p>
  </Card>

  <Card title="File Formats" icon="pencil">
    <p>
      Load and save networks in <a href="/manual/formats/#graphml-files">GraphML</a>, <a href="/manual/formats/#graphviz-dot-files">GraphViz</a>, GML, <a href="/manual/formats/#pajek-files">Pajek</a>, UCINET, Adjacency, EdgeList,
      and <a href="/manual/formats/#two-mode-sociomatrix-files">two-mode sociomatrix</a> formats. GraphML is the native format with full roundtrip support for custom attributes.
    </p>
  </Card>

  <Card title="Multi-relational" icon="add-document">
    <p>
      Load, edit, and save networks with <a href="/manual/gui/#relations">multiple relations</a>. Switch between relations in the Control Panel without losing the others.
    </p>
  </Card>

  <Card title="Random Networks" icon="random">
    <p>
      Generate random networks using <a href="/manual/generate/#scale-free-s-f-networks">Barabási–Albert scale-free</a>, <a href="/manual/generate/#erd%C5%91sr%C3%A9nyi-er-networks">Erdős–Rényi</a>, <a href="/manual/generate/#small-world-sw-networks">Watts-Strogatz small-world</a>, d-regular, and ring lattice models.
    </p>
  </Card>

  <Card title="Famous Networks" icon="seti:favicon">
    <p>Instantly recreate <a href="/manual/generate/#recreating-famous-datasets">classic social network datasets</a> such as Padgett's Florentine families, Zachary's Karate Club, and more.</p>
  </Card>

  <Card title="Web Crawler" icon="rocket">
    <p>
      Automatically build a network of linked web pages by pointing the <a href="/manual/generate/#web-crawler-networks-of-webpages">built-in crawler</a> at any URL.
    </p>
  </Card>

  <Card title="Documentation" icon="seti:info">
    <p>
      A comprehensive <a href="/manual">manual</a> covers every feature — available both online and inside the application via the Help menu.
    </p>
  </Card>

  <Card title="Free Software" icon="linux">
    <p>
      SocNetV is free and open-source (GPL3). Use it anywhere, contribute patches on <a href="https://github.com/socnetv/app">GitHub</a>, or <a href="/bugs">report bugs</a>.
    </p>
  </Card>

</CardGrid>
